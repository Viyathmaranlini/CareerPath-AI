# CareerPath AI 🎓

> Future Skill & Career Intelligence Platform

Students learn skills without knowing future demand.
CareerPath AI analyzes thousands of job postings,
detects emerging skills, and builds a personalized
learning roadmap for every student.

## Features
- 📊 Analyze job postings in real-time
- 🔍 Detect emerging & declining skills
- 📈 Predict future job demand
- 🗺️ Personalized learning roadmap

## Tech Stack
| Layer    | Technology        |
|----------|-------------------|
| Frontend | React + Vite      |
| Backend  | Python + FastAPI  |
| NLP      | spaCy             |
| Database | SQLite/PostgreSQL |
| Forecast | Facebook Prophet  |
